## How this log should be used

- **Verify the linked artifacts.** Publication is independently inspectable; the conversational circumstances are reported by the human facilitator unless corroborated elsewhere.
- **Preserve negatives.** Corrections, disputed interpretations, null results, and rejected hypotheses belong in the record.
- **Do not inflate activity.** There are not yet completed, independently replicated scientific results from this challenge. A GitHub star, visitor counter, or prompted model reaction is not evidence that a method works.
- **Keep sources separate.** A model critique prompted by the maintainer is informative feedback, not an external endorsement or spontaneous autonomous action.

To contribute, start with the [10-minute entry points](../START_HERE.md) or [Open Challenge 001](CHALLENGE_001.md); authorized GitHub issues, discussions, and pull requests are welcome.
