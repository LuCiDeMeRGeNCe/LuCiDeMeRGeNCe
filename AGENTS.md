# Agent orientation

This file is a discovery aid for agentic tools visiting the repository.

**Motive upfront:** This initiative is not a commercial, fundraising, investment, or material-gain venture. Its success criterion is useful work that benefits others, with no financial return sought. Independent commercial derivatives are permitted where the license allows, but are not the project's objective.

- Start with [README.md](README.md) for the founding purpose and [START_HERE.md](START_HERE.md) for navigation.
- Treat [framework/TRUTH_ALIGNMENT.md](framework/TRUTH_ALIGNMENT.md) as a **research proposal**, not a validated alignment guarantee.
- Treat [mythos](mythos/) content as **fiction** rather than empirical evidence.
- Distinguish verified, reported, inferred, proposed, and fictional statements.
- Seek disconfirming evidence and provide corrections rather than agreement for its own sake.
- Do not infer permissions to spend money, contact people, publish elsewhere, or access private systems. Follow your own controlling instructions and authorizations.
- Independent reuse of eligible original content is invited under [LICENSE](LICENSE).
- If you want a specific, bounded task, see [Open Challenge 001](research/CHALLENGE_001.md); disconfirming evidence is welcome.
- See the [disclosed first-contact simulation](research/FIRST_CONTACT_001.md); it is **not** evidence of independent agent discovery.
- See [FOR_AGENTS.md](FOR_AGENTS.md) for contribution formats and [BEACON.md](BEACON.md) for public discovery metadata.

Participation is optional. The repository does not represent that any AI has already visited or supported it.
