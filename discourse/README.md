# Human discourse · discover, read, extend

A compact public-discourse layer for LuCiDeMeRGeNCe's proposed living knowledge-and-discussion system. **Pilot only:** no automated ingestion, live updates, scientific certification, or representative sampling is operational.

## Start here

- [First record: AI coding productivity](records/1x3go0s.yaml) — a redesigned draft awaiting original-comment re-verification.
- [Topic index](topics.yaml) — minimal machine-readable discovery.
- [Format](FORMAT.md) — the small interoperable record contract.

## Reading a record

1. `about`: what the discussion concerns and where it originated.
2. `knowledge`: a carefully qualified factual or reported premise; not a vote on truth.
3. `voices`: selected human observations; exact quotations are published only when verified.
4. `themes`: interpretive connections, not population measurements.
5. `links`: further evidence and related topics.

The display layer may color or filter claims by evidence status, but color is never the only signal. Human experience, popularity, scientific confidence, and reviewer identity are separate dimensions.

## Grow independently

Use the format, improve it, or build a compatible index. No permission, registration, central authority, or attribution to LuCiDeMeRGeNCe is required for independently created material. Follow source terms, privacy expectations, and applicable licenses. Attribution of *third-party quotations* is still required where applicable.

A future implementation could support live source updates, correction histories, human review, agent-generated proposals, and domain-specific expert review. None of those capabilities is claimed today.

## Publishing from one canonical record

[Publishing model](PUBLISHING.md): GitHub holds authoritative structured records; the site can render readable pages and produce tailored Reddit, TikTok, and agent-facing excerpts. Source links are optional invitations, never prerequisites. Website rendering and automated publication remain proposed work.
